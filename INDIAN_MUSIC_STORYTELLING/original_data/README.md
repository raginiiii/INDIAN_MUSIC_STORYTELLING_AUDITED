# Original Source Data — Preservation Area

This directory is reserved for untouched source datasets and source documents supplied for the Indian musical-instrument project.

No Indian project source dataset was available among the accessible uploaded files when this package was generated. Therefore this directory contains no raw data files.

When originals are supplied:
1. Copy them here without modifying their contents.
2. Preserve original filenames and file formats.
3. Record creator, date received, origin, licence/permission and checksum in `research/dataset_sources.csv`.
4. Perform cleaning only on copies stored in a separate derived-data location.
5. Never overwrite originals.

The accessible PDF titled `Chatgpt Create Research Plan.pdf` concerns a Beatles project and is intentionally excluded from this directory.
