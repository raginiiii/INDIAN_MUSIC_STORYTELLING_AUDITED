# Asset Credits and Rights Register

No verified project media assets were available at package creation. The three CSV manifests are header-only.

Before adding an asset:
1. Record its stable asset ID.
2. Record the original source page, not only a direct file URL.
3. Identify creator/performer and date where known.
4. Verify the exact licence or obtain written permission.
5. Record required attribution text.
6. Record whether editing, cropping, downloading, embedding and public display are permitted.
7. Link the asset to relevant entity IDs.
8. Add alt text, caption and transcript/description as appropriate.
9. Verify the asset still works before release.

A blank permission field means permission is unknown, not granted.
