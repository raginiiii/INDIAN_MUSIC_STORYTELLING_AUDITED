# 11 — Media and Asset Guidelines

## Principle
Media is evidence and context, not decoration. Every published asset needs provenance, rights review, attribution and a fallback plan.

## Required manifest fields
Asset ID, type, title, creator, date, source institution/person, source page URL, direct asset URL if permitted, licence, attribution text, permission status, intended use, related entity IDs, caption, alt text, transcript/caption URL where applicable, and verification date.

## Images
- Prefer institutional collections, creator-authorised documentation and appropriately licensed material.
- Verify the licence on the source page, not from a search result thumbnail.
- Check whether the licence allows modification, cropping and public web display.
- Record photographer/creator and required attribution.
- Do not hotlink unless permitted and technically reliable.
- Use responsive image formats and a local approved copy only when rights allow.
- Provide a neutral fallback when an asset fails.

## Audio
- Use recordings only when the hosting/embed method and usage rights are clear.
- Record performer, instrument, recording context, source, licence/permission and attribution.
- Do not download or rehost recordings without permission.
- No autoplay.
- Provide a contextual description and an external source link when embedding is unavailable.

## Video
- Prefer official or institutionally hosted embeds.
- Use the platform's supported embed mechanism.
- Record title, channel/creator, source URL, publication date, relevant timestamp, embed status and permissions.
- Provide captions where available and an external link fallback.

## AI-generated visuals
Generated textures or abstract decorative imagery may be used if clearly treated as illustration, not documentary evidence. Never generate a fictitious maker, musician, community ritual or historical artefact and present it as a real archival image.

## Status values
`verified_licensed`, `permission_granted`, `embed_only`, `permission_required`, `unknown`, `rejected`, `unavailable`.
